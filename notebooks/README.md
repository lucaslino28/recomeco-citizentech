# Notebook de avaliação de IA

Reunimos no [avaliacao_ia.ipynb](avaliacao_ia.ipynb) as tabelas e os exemplos de respostas das 26 perguntas avaliadas pelo juiz. Ele já está executado e pode ser lido pelo GitHub.

O notebook lê `evidencias/ia/antes.json`, da v1, e `evidencias/ia/depois.json`, da v3. Ao abrir os resultados salvos, não é feita uma nova chamada à API.

Essas medidas são das versões que foram testadas. A versão atual do atendimento é a v4. Os resultados dos testes com pessoas estão no [relatório de usuários](../documentacao/ia/usuarios_2026-11-15.md).
