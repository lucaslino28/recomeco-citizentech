# Módulos integrados

| Disciplina | Local do código | Execução |
|---|---|---|
| PCP | Os quatro arquivos Python na raiz: `main.py`, `orientacao.py`, `base_conhecimento.py`, `assistente.py` | Opções 1 e 4; estrutura mantida conforme enunciado. |
| IA | [documentos_ia/](documentos_ia/) | Opção 2: agente, sete fichas fictícias, prompts, golden dataset e juiz. |
| SERS | [energia/](energia/) | Opção 3: cálculos, parâmetros, fontes públicas e interface de energia. |

A navegação é integrada por `main.py`. PCP e SERS não dependem da API; o módulo de IA não reutiliza as fontes de PCP. [Documentação por disciplina](../documentacao/README.md).
